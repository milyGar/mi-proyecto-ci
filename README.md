# Mi Proyecto CI

Proyecto sencillo en JavaScript (Node.js) con funciones de suma y resta
(`src/math.js`), pruebas automatizadas con Jest e integración continua
con GitHub Actions.

## Objetivo

Configurar un flujo completo de desarrollo: controlar el proyecto con Git
y GitHub, y automatizar la ejecución de las pruebas en cada cambio subido
al repositorio mediante integración continua.

## Herramientas utilizadas

- Node.js v24.21.0
- npm 11.19.0
- Jest 30.5.2
- Git
- GitHub y GitHub Actions
- Visual Studio Code

## Cómo ejecutar las pruebas

```bash
git clone https://github.com/milyGar/mi-proyecto-ci.git
cd mi-proyecto-ci
npm install
npm test
```
